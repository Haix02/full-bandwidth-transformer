Standard decode

Latent feedback

Feedback = full residual stream, gated by the token.

e ⊗ h = WU h ⊙ σ(WG e)

Value path is the hidden state. Token is only the gate. If h = 0, the fused input is identically zero — no additive shortcut back to a plain embedding.
